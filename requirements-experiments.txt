# 只有 experiments/ 下的教学脚本才需要这些 —— 起服务、跑测试都不需要。
#
# 为什么单独拆一个文件：
#   这几个包体积大（langgraph 会拖一整套依赖），但 service.py 一行都没 import。
#   混在 requirements.txt 里，别人 clone 下来装依赖就会多装一堆用不到的东西，
#   也会误以为"这个项目用了 LangGraph"—— 其实 LangGraph 只出现在学习过程的教学脚本里。
#
# 装法（想跑 experiments/ 里的脚本时才装）：
#   <你的虚拟环境>\Scripts\python.exe -m pip install -r requirements-experiments.txt
#   （会先自动把 requirements.txt 也装上）
#
# ★ 2026-10-09 补：experiments/ 从 6 个跟课脚本扩到 20 个（按知识点分成 4 个子目录），
#   所以依赖也跟着补齐了 —— 原则是【代码里直接 import 的就显式声明】，
#   跟 requirements.txt 里那句注释同一个原则，不靠"别人会顺手装上"。

-r requirements.txt

# ---- LangGraph：搭 StateGraph / 条件边 / ToolNode / 存档 ----

# 这三个脚本要连一个真实 PostgreSQL，连接串从环境变量 LANGGRAPH_DB_URI 读：

# 不设则默认 localhost —— 也就是说想跑这几个脚本必须先有一个 PostgreSQL，

psycopg[binary]

pillow==12.3.0
