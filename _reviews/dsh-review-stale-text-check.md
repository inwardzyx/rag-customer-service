### ★ 哪类过期陈述它永远抓不到 / 能不能机械判定

**抓不到的类**：① 同义改写（3）；② 锚点不紧邻的（3）；③ 过期的**精准数字**（6）；④ **方向相反**的虚假"已做"宣称——本族只查"说没有、其实有"，反向无规则、无探针；⑤ **任何没被登记进 `STALE_TEXT_RULES` 的过期陈述**。

**⑤ 是根本限制，且照搬不了待办族的成功经验**：待办族能做"面检查"，靠的是**载体可枚举**（〈还没做的〉是一张 Markdown 表，`check:388-400` 逐行取；`check:403-434` 强制每行登记）。过期陈述散落在全文散文里，没有可枚举载体 ⇒ 写不出"每个过期陈述都必须登记"的元检查。

**能不能机械判定"它抓不到"？分两层，答案不同：**
- **"探针死了"（正则失效 / 文件消失 / 计数恒 0）：可以，而且现在完全没做。** 给每条 rule 加一个 `live_anchor`（必须命中的"当前正确说法"，例如 README 里必须存在 `` 已做：`evalset/heldout/` ``）+ 一个"必须算出正值"的探针，任一失败即报错。这样"没响"被拆成"文档干净"和"探针死了"两种**可区分**情形。见洞 1、2。
- **"措辞同义类漏检"：不可以**（无模型判不了同义/反讽/历史叙述）。但可以**换方向**：不枚举坏措辞，改成**断言必须出现的形状**——凡 README 中出现 `evalset/heldout/` 的段落，N 字符内必须出现一个 ≥50 的题数，否则报错。白名单式、会假阳性，但**假阳性看得见、假阴性看不见**，且不依赖措辞。代价：锚点与窗口仍要人定，不保证完备。
